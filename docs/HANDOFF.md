## Решения и почему

- **Только Java и одна зависимость (Material).** Приложение лёгкое, APK release ~1.5 МБ.
  Kotlin-метаданные из AndroidX вырезаются в `packaging`.
- **Foreground service типа `specialUse`.** Оверлей должен жить поверх других приложений,
  подходящего стандартного типа нет. Обоснование — в `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` манифеста.
- **Прозрачность окна ограничена порогом untrusted touch.** Иначе Android 12+ блокирует
  касания сквозь оверлей.
- **Служба специальных возможностей нужна только для слоя `TYPE_ACCESSIBILITY_OVERLAY`.**
  Она не читает содержимое экрана и не получает событий. Так точки видны над шторкой и клавиатурой.
- **Два режима движения.** «Инерция» (как в iOS) отвечает на ускорение. «Гироскоп» держит точки
  привязанными к миру, как в большинстве Android-аналогов.
- **Физика в чистых классах.** Оценка ускорения переводит сигнал в мировые оси, затем в оси экрана.
  Оценка подавляет вращение телефона в руке. Мягкая пружина возвращает поле точек.
  Всё это тестируется без устройства.
- **Вибрация выбирается по возможностям вибромотора, а не по модели телефона.**
  Длительные примитивы (SLOW_RISE, THUD) не используются.
- **Интерфейс без слов «машина»/«автомобиль»**, при этом надпись VEHICLE MOTION CUES остаётся.
  Это решение владельца при переименовании (52c3643).

## Известные проблемы и пробелы

- Язык по умолчанию — русский (`res/values`). На других языках, кроме английского,
  интерфейс будет русским. Для Google Play стоит сделать английский языком по умолчанию.
- Английский перевод на устройстве ещё не смотрели (длина строк, переносы).
- Нет LICENSE и скриншота в README.

## Как продолжить в другом агенте

1. `git clone https://github.com/dmjtrj/giro-android && cd giro-android`
   (на этой же машине можно работать в существующей папке — `.toolchain/` уже на месте).
2. `./scripts/setup-toolchain.sh`, затем `source ./env.sh && ./gradlew testDebugUnitTest`.
3. Запустить агента в корне проекта. Правила он найдёт сам:
   Codex, Cursor, Windsurf, Copilot, Amp — `AGENTS.md`; Claude Code — `CLAUDE.md`;
   Gemini CLI — `GEMINI.md`; Aider — `.aider.conf.yml`. Все они ведут на `AGENTS.md`.
4. Первый промпт: «Прочитай AGENTS.md и docs/HANDOFF.md, посмотри git log и скажи,
   что понял о проекте. Ничего не меняй».

## Окружение Claude Code и как его воспроизвести

Папка `.claude/` в `.gitignore`, поэтому её содержимое в git не попадает. Ниже — что там есть.

- **Slash-команды, skills, subagents:** в проекте нет (`.claude/commands`, `skills`, `agents` отсутствуют).
- **Hooks:** нет.
- **MCP-серверы:** нет, `.mcp.json` отсутствует.
- **`.claude/settings.json`:**
  - переменные `ANDROID_HOME` и `JAVA_HOME`. В другом инструменте достаточно делать `source ./env.sh`;
  - песочница: чтение домашней папки закрыто, кроме проекта, `~/Library/Android/sdk`,
    `~/.gradle` и `~/.android`; запись разрешена в `~/.gradle` и `~/.android`;
    локальные порты разрешены (для adb). В Codex то же самое — `sandbox_mode = "workspace-write"`
    и добавление этих папок в `writable_roots`; в других инструментах — их собственная модель песочницы.
- **`.claude/settings.local.json`:** разрешения, накопленные во время настройки тулчейна
  (git, curl к Adoptium/GitHub/dl.google.com). Переносить не нужно: тулчейн уже скачан в `.toolchain/`.
- **Память сессий** (`~/.claude/projects/...`): из неё в репозиторий перенесено главное —
  автор коммитов и то, что пушит владелец (см. `AGENTS.md` → Git).
