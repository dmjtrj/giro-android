Инструкции для coding-агентов (Codex, Cursor, Gemini CLI, Claude Code и др.).
Перед работой прочитай `README.md` (что делает приложение) и `docs/HANDOFF.md`
(текущее состояние, решения, известные проблемы, что дальше), затем `git log`.

## Проект

«Гиро» — Android-приложение против укачивания в духе iOS Vehicle Motion Cues:
точки по краям экрана повторяют ускорение транспорта поверх всех приложений.

- Только **Java** (Kotlin не используем), Groovy DSL, version catalog `gradle/libs.versions.toml`.
- compileSdk / targetSdk **37** (Android 17), minSdk **31**, Java 21.
- Зависимости: только `com.google.android.material` и JUnit 4. Новые библиотеки — только по согласованию.
- Пакет `com.motioncues.app`; раскладка по пакетам описана в `README.md` → «Устройство».
- Целевое устройство для проверки — Pixel 8 на Android 17.

## Сборка и тесты

JDK, Android SDK и Gradle-кэш лежат внутри проекта в `.toolchain/` (в git не попадает):

```bash
source ./env.sh
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # юнит-тесты JUnit 4
./gradlew lintDebug
./gradlew assembleRelease      # R8 + shrinkResources
```

- `env.sh` не добавляет `build-tools` в PATH; для `apksigner`/`zipalign`:
  `export PATH="$ANDROID_HOME/build-tools/37.0.0:$PATH"`.
- Все файлы проекта, включая тулчейн, держим внутри папки проекта.
- Перед коммитом: юнит-тесты зелёные, lint без новых предупреждений.

## Стиль кода

- Пиши как окружающий код: комментарии короткие и по-русски, имена и идиомы как в соседних файлах.
- Логику, которую можно проверить без устройства (датчики → сигнал, пружина, поле точек,
  палитра, профили, рецепты вибрации), держи в чистых классах и покрывай тестами в `app/src/test`.
- Строки интерфейса — в `res/values/strings.xml`, сейчас только русская локаль.
- В текстах интерфейса не упоминай «машину»/«автомобиль» — формулировки абстрактные («в пути»).
- Не меняй надпись VEHICLE MOTION CUES и стиль заголовка на главном экране.
- Иконки — VectorDrawable; у launcher-иконки есть монохромный слой для тематических иконок.

## Git

- Ветка `master` — стабильная. Каждая функция — отдельная ветка `feature/NN-alias`
  (следующий номер — 10), вливается в master через `git merge --no-ff`, удаляется только по просьбе владельца.
- **Коммить и вливай только после явного подтверждения владельца.** Пушит владелец сам.
- Автор коммитов: `dmitryosorgin <dmitryosorgin@gmail.com>`.
- Сообщения коммитов по-английски: `feat(NN): ...`, `docs: ...`; в теле — список изменений
  и на чём проверено. Строку `Co-Authored-By` агента в конце оставляем.

## Безопасность и устройство

- Не включай за пользователя службу специальных возможностей и не выдавай системные разрешения.
- При работе с телефоном через adb не нажимай ничего вне нашего приложения, сначала проверь,
  какое приложение на переднем плане. Не снимай скриншоты шторки и личного контента.
- Ключ релизной подписи лежит вне репозитория (`~/keys/giro-release.jks`), никогда его не коммить.
  `*.jks`, `*.keystore`, `*.apk` уже в `.gitignore`.
- Не пиши в файлы проекта токены, пароли и учётные данные прокси.
